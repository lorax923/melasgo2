# MelasGo2 — By Lorenzo Piras
Avvio locale: `python server.py` -> http://localhost:8000

## Metterla online (serve per amici + APK)
1. Carica la cartella su GitHub e collegala a Render.com (Web Service, gratis): Start command `python server.py`.
   (Per non perdere i dati al riavvio aggiungi un Disk, oppure usa Railway/Fly.io/un VPS.)
2. Ottieni un link tipo https://melasgo2.onrender.com

## Installazione
- PC (Chrome/Edge): icona "Installa" nella barra indirizzi.
- Android: apri il link in Chrome -> menu -> "Installa app".
- iPhone: apri il link in Safari -> Condividi -> "Aggiungi a Home".
- APK: vai su https://www.pwabuilder.com, incolla il link, "Package for stores" -> Android -> scarica l'APK.
  Poi caricalo (es. Google Drive/GitHub Releases) e condividi il link di download.
